# OroEcoDynamics

**A mathematical simulation framework for the oral environment.**

OroEcoDynamics is an open-source scientific computing project exploring the interactions between oral microbial metabolism, salivary chemistry, pH fluctuations, and dental hard-tissue mineral dynamics.

## Motivation

The oral cavity is a dynamic biological and chemical ecosystem. Microbial metabolism, dietary carbohydrate exposure, salivary clearance, and buffering mechanisms interact to influence the chemical environment surrounding dental tissues.

OroEcoDynamics aims to represent these interactions through mathematical models and numerical simulations.

## Initial objectives

- Model sugar clearance and acid production.
- Simulate plaque pH dynamics following carbohydrate exposure.
- Investigate the influence of salivary buffering and flow.
- Explore enamel demineralization and remineralization.
- Perform parameter sensitivity and uncertainty analysis.
- Compare simulated behavior with published experimental observations.

## Scientific approach

The project will prioritize:
- Mechanistically interpretable mathematical models.
- Reproducible numerical experiments.
- Explicit assumptions and parameter provenance.
- Validation against published experimental evidence.
- Modular and extensible scientific software architecture.

## Technology

Python · NumPy · SciPy · SymPy · Matplotlib

## Project status

Early research and development.

**Disclaimer:** OroEcoDynamics is an educational and research-oriented simulation project. It is not a clinically validated diagnostic or caries-risk prediction system.
